
# 🛒 E-Commerce UI Design Project

**Developers Hub – JavaScript Based Assignment**

## 📌 Project Overview

This project focuses on building a **basic E-commerce User Interface (UI)** using **HTML, tailwind CSS, and JavaScript**.
The goal is to practice **UI development**, **DOM manipulation**, and **cart functionality** using JavaScript.

The project is divided into **two main tasks**.

## 🧩 Technologies Used

* HTML5
* Tailwind CSS
* JavaScript (ES6)
* Browser DOM API

## 🎯 Task Breakdown

## ✅ Task 1: Build E-commerce UI & Display Products Using JavaScript

### 🔹 Objective

Create a responsive E-commerce UI where products are **dynamically rendered using JavaScript**, not hardcoded in HTML.

### 🔹 Requirements

* Create a clean UI layout (Navbar, Product Section, Cart Section)
* Store product data in a JavaScript array
* Use JavaScript to display products on the page
* Each product should include:

  * Image
  * Title
  * Price
  * Discount (if available)


## ✅ Task 2: Product View, Discount Management & Cart Functionality

### 🔹 Objective

Enhance user interaction by implementing **product viewing**, **discount calculation**, and **cart management**.

---

### 🔹 Features to Implement

#### 🛍️ 1. Click to View Product

* When user clicks on a product, show:

  * Product details
  * Original price
  * Discounted price

#### 💸 2. Discount Management

* Calculate discounted price using JavaScript

  * Final discounted price


#### 🛒 3. Cart Functionality

* Add product to cart
* Display cart items dynamically
* Show total cart price
* Increase or decrease items (optional)

#### ❌ 4. Delete Cart Items

* Add "Remove" button for each cart item
* On click:

  * Remove item from cart array
  * Update UI instantly
  * Recalculate total price

## 🧠 Learning Outcomes

* JavaScript DOM manipulation
* Dynamic UI rendering
* Event handling
* Cart logic implementation
* Price & discount calculation
* Clean UI structuring
